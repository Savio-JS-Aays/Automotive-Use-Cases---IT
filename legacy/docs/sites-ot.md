# Module — Sites & OT

- **Route:** `/sites-ot` (`?site=LOC0025` opens a site, `?incident=` an incident). Replaces the unrouted IT-to-OT page, whose zones and Purdue layers were fabricated with `index % 4`.
- **Code:** `src/modules/sites/SitesModule.jsx`
- **Data:** `it_site_overview`, `it_site_detail` (migration 007) over `fact_network_events` (regenerated by 005: one row per site × device type × day, Apr–Sep 2026) joined to the shared `dim_location` / `dim_region`.

## Device mix per site type

Plant: Edge Router, Switch, IoT Gateway, Scanner · Warehouse: Edge Router, Switch, Scanner · Dealer: Edge Router, Scanner. Columns: `avg_ping_ms`, `disconnect_count`, `downtime_minutes`, `packet_loss_pct`.

## KPIs

| KPI | Formula |
|---|---|
| Site Network Availability | 1 − Σ device downtime ÷ (device-days × 1440) |
| Degraded Sites | sites with availability < 99.5% or ping > 1.5× the typical for their site type and device |
| Disconnects per Site-Day | Σ disconnects ÷ (sites × days) |
| Plant Edge Latency | mean ping of plant edge routers |
| Site Incidents | IT incidents raised against a specific site |

## Purdue layers (plants in scope)

| Layer | Basis | Status |
|---|---|---|
| L4 Enterprise (ERP) | SAP ERP service availability | Healthy ≥ 99.9%, Degraded ≥ 99%, else Critical |
| L3 Site operations (MES) | min(MES service availability, plant edge-router availability) | same |
| L2 Supervisory | plant switches + IoT gateways | same |
| L1 Field devices | plant scanners | same |

## Visuals

Region cards (select = set the global Region filter) · site grid grouped Plants / Warehouses / Dealers, coloured by availability, amber ring = high latency · degraded-sites table · **site drawer**: downtime minutes per day stacked by device, ping per device, incidents at the site → incident drawer.

## Stories

Pune 02 plant (LOC0025): edge router and switch instability in Sep-2026 (94.95% availability, 8 MES network incidents; L3 = Critical). East-region dealers: ping up ~80% since Jul-2026 (14 of them degraded on latency). Routine sites run at 99.96–100%.
